## แผนตำแหน่ง

| หน้าจอ | การจัดวาง |
|---|---|
| จอกว้าง | สมุดและปากกาวางเคียงข้างกัน หลายคอลัมน์ 1280 × 800 |
| จอแคบ | การ์ดสินค้าเรียงลงมาทีละใบ (1 คอลัมน์) และ form ปรับความกว้างตามพื้นที่ 390 × 844 |

## เครื่องมือและเหตุผล

| ส่วน | เครื่องมือ | เหตุผล |
|---|---|---|
| ส่วนหัว (โลโก้ + เมนู) | Flexbox | เรียงในแถวเดียว และให้เมนูขึ้นแถวใหม่ได้เมื่อพื้นที่ไม่พอ |
| รายการสินค้า | Grid | กำหนดจำนวนคอลัมน์ได้ชัดเจน และปรับตามความกว้างจอได้ |

## ลำดับ Tab

1. เมนูหลัก (`<nav>`)
2. สินค้า (การ์ดสมุด -> การ์ดปากกา)
3. ตะกร้าตัวอย่าง
4. ช่องเลือกสินค้า (form)
5. ปุ่มส่ง/เพิ่มลงตะกร้า
